# PI 液位換算與日使用量 17% 查核

2026-10-06 依使用者更正實作。本規則取代下降速率、22～26 小時區間及每端 ±1 cm 容差。

1. 先以過往 PI 與人工液位建立固定高度關係。12 槽使用歷史配對的經驗線性模型；CT-2 硫酸沿用經歷史資料支持的 1.99 cm/% 設定。擬合期間為 8/1～9/10，驗證期間為 9/11～10/4，不在輸入當日重新擬合來迎合結果。來源見 `PI_Scale_Verification_20261006.json` 與 `piDailyConversions.js`。
2. PI 期初、期末值先換算為 APP 液位公分，再分別依桶槽形狀、尺寸與既有容積公式換算公升。臥式槽不得把液位下降量直接當成使用量。
3. 人工日使用量＝APP 前次已存公升＋已登錄補藥量－本次液位換算公升；PI 日使用量＝PI 期初公升＋同一筆已登錄補藥量－PI 期末公升。PI 上升偵測僅供提示，不再把上升估算量加進使用量。
4. 差距＝｜PI 日使用量－人工日使用量｜÷ 人工日使用量 ×100%。嚴格小於 17% 通過，等於或高於 17% 提醒。17% 為使用者考量抄表時間約 ±2 小時所設定的概估容差，不再疊加其他時間或讀值誤差。
5. 人工、PI 皆零時差距為 0%；只有人工為零時顯示無法計算百分比並提醒，不除以零。用量為負或 PI 資料不足時維持未完成查核。

時間沿用業務日的台北午夜邊界：例如 10/5 用量，人工結算液位概略對應 10/6 00:00。CT-1 硫酸保留 15 分鐘中位數抑制雷達波動，避免波動誤當補藥；畫面明示。氨水、消泡劑、微生物分散劑、非氧化型殺菌劑仍免比對。

回傳 PI 兩端液位、公升、人工與 PI 日使用量、差距百分比及固定 17% 門檻，方便逐槽追查。歷史公式為經驗關係，不代表原廠儀表校驗；液位誤差可能在低用量日放大為較高的用量百分比差異，不放寬門檻掩蓋。

驗證：49 項測試通過，涵蓋兩種桶槽形狀、固定歷史換算、17% 嚴格上下邊界、零用量、補藥共用與免比對藥劑。舊速率欄位仍留在型別供歷史紀錄相容，但新查核不回傳或使用。

日使用量依 APP 公升儲存精度取小數兩位後比較，避免零用量因小數截位變成極小分母。
